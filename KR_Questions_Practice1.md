# Главная проблема DevOps: 
- Устраняет "Стену недопонимания" между разработчиками и операциями, автоматизируя процессы.

# CALMS: 
- Culture (Культура), Automation (Автоматизация), Lean (Бережливость), Measurement (Измерения), Sharing (Обмен знаниями).

# git add vs git commit:
- git add — добавляет файлы в staging area (индекс)
- git commit — сохраняет изменения из staging area в локальный репозиторий

# SSH-ключ: 
- Обеспечивает безопасную аутентификацию без ввода пароля, используя криптографические ключи.

# origin и main:
- origin — имя удаленного репозитория (по умолчанию)
- main — название основной ветки

# DORA:
- Deployment Frequency (Частота развертывания) — как часто команда выпускает изменения в продакшен.
- Lead Time for Changes (Время выполнения изменений) — время от коммита кода до его попадания в продакшен.
- Change Failure Rate (Процент неудачных изменений) — доля релизов, требующих отката или хотфиксов.
- Time to Restore Service (Время восстановления сервиса) — сколько времени требуется для восстановления после инцидента.
