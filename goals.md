# Мои цели на семестр

## Цели по курсу DevOps

### 1. Освоить основы контейнеризации с Docker
- Научиться создавать Dockerfile
- Понять работу с docker-compose
- Запустить свой первый контейнер с веб-приложением
- Создать многоконтейнерное приложение

### 2. Настроить полноценный CI/CD пайплайн
- Изучить GitHub Actions
- Настроить автоматические тесты при push
- Реализовать автоматический деплой на сервер
- Научиться работать с секретами и переменными окружения

### 3. Изучить Infrastructure as Code с Terraform
- Понять концепцию "инфраструктура как код"
- Научиться описывать инфраструктуру в .tf файлах
- Развернуть тестовое окружение в облаке (Yandex Cloud)
- Освоить базовые команды: terraform init, plan, apply
